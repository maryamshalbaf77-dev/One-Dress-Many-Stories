ONE DRESS, MANY STORIES — prototipo web

Abre index.html para navegar por las páginas. La segunda página (Cómo funciona / guide.html) incluye la imagen de referencia facilitada.

Para grabar vídeo con la cámara del móvil, sirve esta carpeta desde un servidor HTTPS (o localhost). Abrir directamente el archivo mediante file:// puede bloquear la cámara.

El sitio es un prototipo local: no se conecta a un proyector, no procesa el vídeo para projection mapping y no dispone de cola compartida. La galería guarda únicamente el nombre y efecto en el navegador local, NO los vídeos.

Archivos: index.html, guide.html, create.html, gallery.html, style.css, script.js, assets/projection-guide.png.
